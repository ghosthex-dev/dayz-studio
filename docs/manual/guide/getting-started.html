Chapter 1: Foundations & Getting Started ​

Welcome to DayZ Studio! If you have ever wanted to build your own survival outposts, custom quests, talking NPC traders, or post-apocalyptic storylines in DayZ—without learning complex programming or messing with command-line tools—this textbook is for you.

💡 The Problem with Traditional DayZ Modding ​

Historically, building a custom DayZ server experience required juggling multiple fragile tools:

  • Writing C++ style scripts in Bohemia's Enforce Script language.
  • Hand-crafting massive JSON configuration files with zero error checking.
  • Using command-line binarizers (MakePbo, DSUtils, AddonBuilder).
  • Forcing every player joining your server to install heavy framework mods (like Community Framework (CF) or DayZ Expansion).

🧰 Key Concepts & Vocabulary ​

Before we install anything, let's establish a beginner-friendly foundation:

  • PBO (.pbo): Short for Packed Bohemia Object. Think of it as a .zip file specifically formatted for DayZ. All scripts, models, textures, and sounds are packed into .pbo files.
  • Cryptographic Keys (.bikey & .biprivatekey): DayZ requires security keys to protect against cheating. Your private key signs your mod. Your public key (.bikey) is copied to the server's keys/ directory so the server allows players to join.
  • Central Economy (CE): DayZ's automated engine system that manages loot spawning, zombie distributions, and animal populations.
  • Vanilla Compatible: Your mod runs on regular DayZ servers without requiring players to download third-party frameworks.

🚀 Prerequisites (Free on Steam) ​

Ensure the following tools are installed on your Windows PC:

  1. DayZ (Game Client): Your normal Steam installation. DayZ Studio reads authentic terrain, buildings, and textures directly from your local game files.
  2. DayZ Tools: Free on Steam under Library ▸ Tools ▸ DayZ Tools.

    IMPORTANT

    You must launch DayZ Tools at least once after installing it. This allows it to write its internal registry paths to Windows so Studio can use its cryptographic signing tools.

  3. DayZ Server (Optional): Also free under Steam Tools. Recommended if you want to test multiplayer server networking directly inside the IDE.

📥 Installing DayZ Studio ​

  1. Download DayZStudio-Setup-<version>.exe from the GitHub Releases.
  2. Run the installer.

    NOTE

    Windows SmartScreen: Because DayZ Studio is an independent alpha tool, Windows may display "Windows protected your PC". Click More info, then Run anyway.

  3. DayZ Studio installs to %LOCALAPPDATA%\DayZStudio without requiring administrator privileges.
  4. Your personal projects, custom currency textures, and security keys live safely in: Documents\DayZStudio

⚙️ The First-Time Map Extraction (~10 min, once per map) ​

Because DayZ Studio respects Bohemia Interactive's copyright, it redistributes zero proprietary game files. Instead, on first run, it extracts terrain elevation and 3D buildings directly from your own legally owned DayZ game:

  1. Open DayZ Studio and go to the Map tab (Alt + 1).
  2. In the right-hand panel, click ⬇ Extract … imagery from DayZ.
  3. Switch to the Game setup tab on the left:
    • Click ⬇ Capture from the game (DayZ will launch briefly to measure terrain elevations, then close automatically).
    • Click ☰ Capture class list (~5,000 items, weapons, vehicles, and props are cataloged).
  4. Click 🌲 Capture world objects (~3 minutes). This builds the high-speed 3D streaming scene so you can see all natural trees, rocks, and buildings in real-time.

TIP

Mod Terrains: Chernarus+, Livonia, Sakhal, and Nasdara are supported out of the box. Community maps like Namalsk and Deer Isle are also automatically discovered from your Workshop subscriptions!
