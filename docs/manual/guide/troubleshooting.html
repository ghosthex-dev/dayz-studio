Chapter 9: Troubleshooting & FAQ ​

Quick solutions for common beginner questions and setup issues.

🛠️ Common Issues & Fixes ​

"Could not start the studio server" ​

  • Cause: Port 8765 is occupied by another local background web service.
  • Fix: Close conflicting background applications or open Windows Task Manager and end any leftover python.exe processes.

Black 2D Map / "No terrain data yet" ​

  • Cause: Satellite imagery has not been extracted yet.
  • Fix: Switch to the Map tab (Alt + 1). In the right panel, click ⬇ Extract … imagery from DayZ.

Capture buttons are greyed out ​

  • Cause: DayZ was not found in registered Steam library folders.
  • Fix: Ensure DayZ is installed through Steam. If DayZ is installed on a secondary drive, verify that drive is added in Steam under Settings ▸ Storage.

Mod exported but shows "Not signed" ​

  • Cause: DayZ Tools is either missing or has never been initialized.
  • Fix: Install DayZ Tools from Steam (Library ▸ Tools ▸ DayZ Tools). Launch DayZ Tools at least once so it writes its paths to the Windows registry, then export again.

Kicked from local test server: "Game restart required" ​

  • Cause: Dedicated servers enforce BattlEye security.
  • Fix: Do not launch DayZ manually; use DayZ Studio's ② Join with the game button, which correctly initializes BattlEye.

Windows SmartScreen: "Windows protected your PC" ​

  • Cause: DayZ Studio is an independent alpha release without an expensive EV enterprise code-signing certificate.
  • Fix: Click More info, then click Run anyway.

🐞 Built-in Bug Reporter ​

If you encounter unexpected behavior:

  1. Go to File ▸ 🐞 Report a bug…
  2. Describe what happened and click Open GitHub issue.
  3. Studio zips its application log, recent editor errors, and the latest DayZ logs into Documents\DayZStudio\BugReports.
  4. It opens a pre-filled GitHub issue in your browser and displays the bug report folder. Simply drag the .zip file into GitHub and click submit!
