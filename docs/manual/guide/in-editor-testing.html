Chapter 7: In-Editor Playtesting with the Docked Game Viewport ​

One of the most powerful features of DayZ Studio is the Docked In-Engine Viewport. You never have to guess how your outpost looks or how your quests feel in the real game engine.

⚡ The Instant Testing Loop ​

Traditional Testing Workflow (Slow):
[Edit Code] ➔ [Repack PBO] ➔ [Sign Key] ➔ [Copy to Server] ➔ [Restart Server] ➔ [Launch DayZ] (5–10 Minutes)

DayZ Studio Testing Workflow (Instant):
[Edit in Studio] ➔ [Switch to Game Tab] ➔ [Walk Around Immediately] (<10 Seconds)

🎮 How the Docked Viewport Works ​

Anatomy of the Live Game Viewport ​

As captured above running on Chernarus+:

  • Real In-Game Rendering: The docked borderless viewport runs the genuine DayZ engine directly inside DayZ Studio.
  • Live Sync & Auto-Pull (● Connected): Changes made in the editor automatically push to the running game in sub-second time.
  • 🎒 Loot & Infected Toggle: Run around with dynamic loot spawns, wild animals, and roaming zombies active—or turn it off for an uninterrupted building session.
  • Camera Sync: Check 3D tab drives game camera or click + Fly to selection to instantly snap the game camera to any selected building or prop.
  • 🧪 Play-Test Quests: Boots the compiled quest runtime directly inside the viewport with test controls so you can play through your questlines without restarting your server.
  • Game Class Library (Left Panel): Search over 6,500 game classes across weapons, buildings, infected, vehicles, clothing, and props.
  • Inspector & Terrain Controls (Right Panel): Toggle game terrain imagery, brightness adjustments, town labels, and the 150m performance heatmap.
  1. Switch to the Game tab (Alt + 2).
  2. DayZ Studio boots a borderless, offline DayZ client embedded directly inside the editor layout.
  3. Active Central Economy (CE): Loot spawns dynamically in buildings, wild animals roam the wilderness, and infected populate towns.
  4. Sub-Second Live Synchronization: Move an object in DayZ Studio, and its position updates in the running game viewport in under one second!
  5. Bidirectional Selection: Click an object inside the game window, and it highlights inside Studio's Inspector.
  6. Live Quest Beacons: Translucent trigger cylinders, interaction pillars, and flow lines render visibly inside the game viewport so you can visually confirm your quest trigger radiuses.

🕹️ In-Game Testing Shortcuts ​

  • Standard Controls: Walk in 1st/3rd person using WASD and mouse look.
  • Camera Focus (F): Fly the camera directly to your currently selected studio prop.
  • Teleport (tp): Type tp <location> or coordinates in the floating console (`Ctrl + ``) to teleport anywhere on the map instantly.
  • Toggle CE: You can toggle 🎒 Loot & infected off anytime in the toolbar if you prefer a peaceful environment while arranging buildings.

🌐 Local Dedicated Multiplayer Server ​

Need to verify multiplayer RPCs, player reconnection, or BattlEye compliance?

  • In the toolbar, click Test on local server.
  • DayZ Studio launches a real local DayZServer_x64.exe instance with your mod loaded.
  • Click ② Join with the game to launch the DayZ client with BattlEye security enabled and verify multiplayer functionality.
